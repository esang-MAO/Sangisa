How to start Sangisa on your computer (HQ vocals, FLAC/MP3, long songs)

The song is processed by Sangisa running on your own computer, so it never leaves your devices. On the computer, separation takes about 1–3 minutes on an Apple Silicon Mac or NVIDIA GPU, 10–15 minutes on other machines.

  1. Once: install uv, then in a terminal run 
    git clone https://github.com/esang-MAO/Sangisa
cd Sangisa
uv sync --extra separation
  2. Each time: in the Sangisa folder run 
    uv run sangisa serve
    and open http://localhost:8765 (this page works too in Chrome, Edge and Firefox).
  3. From a phone or tablet on the same Wi-Fi: start it with 
    uv run sangisa serve --lan
    and scan the code it prints with the phone's camera.

Making kits on the phone itself, without a computer, isn't available yet.

    Loading it into Koala
    1. Share… → Save to Files (or AirDrop it), then tap the .zip in Files to unzip it.
    2. In Koala, open the sample browser and go to the kit's Bank_A folder (add the folder as a location if needed).
    3. Select all the files and drag them onto the first empty pad: they fill the pads in number order.

    If the kick doesn't land where it is here (bottom-left), switch the pad order.
