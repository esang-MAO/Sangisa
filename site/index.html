How to start Sangisa on your computer

The song is processed by Sangisa running on your own computer, so it never leaves your devices. Stem separation needs a computer: about 1–3 minutes on an Apple Silicon Mac or NVIDIA GPU, 10–15 minutes on other machines.

  1. Once: install uv, then in a terminal run 
    git clone https://github.com/esang-MAO/Sangisa
cd Sangisa
uv sync --extra separation
  2. Each time: in the Sangisa folder run 
    uv run sangisa serve
    and open http://localhost:8765 (this page works too in Chrome, Edge and Firefox).
  3. From a phone or tablet on the same Wi-Fi: start it with 
    uv run sangisa serve --lan
    and scan the code it prints with the phone's camera.

Making kits on the phone itself, without a computer, isn't available yet.

Open a kit

Drop a kit .zip here (from sangisa or the Build a kit GitHub Action), or try the Demo kit: built by the real pipeline from a generated song.

    Tap a pad to play it. Keys: Z X C V bottom row … 1 2 3 4 top row. Loops keep playing until you tap them again.

    Every candidate in the song

    Solid marks are on pads, faint ones are backups. Click one to hear it, then Put on pad to swap it onto the selected pad.

    Releasing music with uncleared samples can require permission from the rights holders. Only build kits from audio you own or have permission to sample.
